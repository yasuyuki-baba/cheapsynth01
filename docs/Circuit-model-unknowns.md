## 3. 不明箇所と混同しない事項

- サンプルレート対応、数値精度、ブロック分割、MIDIイベント位置、
  リリース状態の維持は、ソフトウェアとして検証できる事項です。
- 全体4倍オーバーサンプリングはデジタルの折り返し対策であり、
  カスタムICの内部モデルではありません。
- 回帰テスト成功は、上表の未校正値が実機と一致することを保証しません。
- 内部仕様が不足していても、外部配線・部品値・メーカー操作仕様まで
  「不明」とする必要はありません。確定した情報は保持します。

## 4. 資料が得られた際の更新順

1. 正確な型番・出典・ページを記録し、外部配線と対応づける。
2. 上表のどの未確定項目を解消するかを明示する。
3. 制御則・単位・時間の定義を先に定め、独立した期待値でテストする。
4. 近似実装を置換し、プリセット・演奏中の状態・音色への影響を確認する。

必要資料の詳細は `Requested-circuit-resources.md` を参照。
本一覧の作成では、本番音声処理を変更していません。
